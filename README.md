# Tennico – tennis academy site

One-page site in plain HTML/CSS/JS (no build step). Open `index.html` in a browser.

Includes scroll-reveal and card-flip animations, rolling counters, hero parallax, an image slideshow, FAQ accordion, pricing table, marquee ticker and a responsive mobile menu.

> Images and video currently load from the original Framer template's CDN — replace them with your own before publishing.
